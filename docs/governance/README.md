# Governance Protocols

This directory will hold detailed governance protocol documents (proposal formats, amendment procedures, dispute resolution steps, facilitation guidelines) once they are defined.

The current high-level governance skeleton lives in [GOVERNANCE.md](../../GOVERNANCE.md) at the repository root. Every unresolved specific is tracked with a stable ID in [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md), the authoritative registry for this project. Detailed protocols belong here once those questions are resolved — do not invent protocol detail here merely to fill this directory.
