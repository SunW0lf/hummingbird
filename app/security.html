Security & Contact

Hummingbird's Phase 0/1 site is static, with no accounts, forms, or database. The realistic attack surface is therefore concentrated in the source and deployment pipeline: the GitHub repository and Actions workflow, Cloudflare deployment credentials, and the small set of build-time dependencies.

A dedicated private security contact channel has not yet been established. Until then, do not open a public issue for a security vulnerability. Establishing and verifying a private reporting channel is a blocker for completing Phase 1 or publishing the repository, whichever comes first.

The repository's SECURITY.md is the authoritative source for the current threat model, controls, and unresolved security questions.
