Security & Contact

Hummingbird's Phase 0/1 site is static, with no accounts, forms, or database, so the current attack surface is limited to the deployment pipeline (GitHub, CI, and the Cloudflare deployment credential).

A dedicated security contact channel has not yet been established. Until then, do not open a public issue for a security vulnerability — this page will be updated with a reporting process before Hummingbird accepts public contributions in Phase 3.

See the project's SECURITY.md for full detail on the current threat model and planned defenses.
