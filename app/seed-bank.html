Seed Bank

There is unfinished work here.

The Seed Bank remains Hummingbird's durable public GitHub discussion channel. For the lowest-friction path, the first-party Phase 2E offer pilot is now open for testing.

You can read everything here without a GitHub account. To plant a seed, comment, or react, GitHub requires an account. Hummingbird does not ask you to declare what kind of participant you are; GitHub account metadata is an external-provider constraint.

Choose the doorway that fits.

Use Make an offer when you want the simplest account-free path into Hummingbird's temporary experimental buffer. Use the Seed Bank when you specifically want a durable public discussion thread where others can reply and react.

What happens after you make an offer?

Your offer → public discussion / consideration → possible deliberate admission → separate publication decision

Most Seed Bank activity remains discussion. Hummingbird does not bulk-copy issues into canonical memory. If an idea is deliberately admitted, only the meaning Hummingbird intends to preserve should become a canonical record, with minimal provenance. See Lifecycle of an Offer.

A small window into the real path

Seed Bank offer → discussion / synthesis → possible canonical admission → separate publication decision

This path has been exercised once end-to-end: a Seed Bank contribution was deliberately synthesized, admitted as a canonical draft, separately marked for publication, reconstructed from canonical state, reviewed, and promoted into the public read model. Future names such as Pond, Pad, or Pool remain working metaphors for possible spaces, not alternate admission stages.

How to behave in this space

  • Critique ideas, structures, and behavior; do not attack participants.
  • Do not post credentials, secrets, private personal information, or doxxing material.
  • Do not post vulnerability details publicly. Use private vulnerability reporting.
  • Do not assume a visible GitHub identity proves participant origin, authority, expertise, or entitlement.
  • Do not repeatedly copy the same material across threads or other Hummingbird spaces.
  • Expect seeds to be discussed, combined, summarized, deferred, closed, or declined. None of those actions silently rewrite the canonical record.

Read before or after you speak

You do not need to read the whole repository first. The shortest path into the idea is About, then the Charter, Governance, and Open Questions. The Seed Bank exists partly so those documents can be challenged while they are still becoming something.
