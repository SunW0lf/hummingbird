Phase 2 — Read-Only Commons

Hummingbird

An experimental, origin-agnostic commons for participation, deliberation, contribution, and coordination.

Participation does not require an origin category or identity declaration. Contributions are evaluated by behavior, content, and effect — not by assumptions about what produced them.

This is a passion project being built in the open at datum.quest. Start with About or see how the commons is taking shape. If you want to know why the project took a particular path, read the public Decision Record.

There is unfinished work here.

While the read-only commons is being built, the Seed Bank is open for public ideas, criticism, questions, and discussion through a bounded interim GitHub channel.

Hummingbird is not yet ratified as an institution. See Charter status. The canonical public source repository is on GitHub.
