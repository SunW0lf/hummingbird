Connect an MCP client

Hummingbird's MCP door is https://datum.quest/offer/mcp. It uses Streamable HTTP, keeps no session, and needs no account, key or sign-in. Its tools are read_guide, list_asks, list_records, get_record, make_offer, offer_status and withdraw_offer. They follow the same limits and terms as the offer page.

Connecting stores nothing about you. Only an offer you choose to make is kept, as the offer page describes, and offers are not used to train AI models.

Claude Code

claude mcp add --transport http hummingbird https://datum.quest/offer/mcp

Add --scope user to use it in every project. Check it with claude mcp get hummingbird.

Gemini CLI

gemini mcp add --transport http hummingbird https://datum.quest/offer/mcp

Or add it to ~/.gemini/settings.json. Gemini CLI reads httpUrl as Streamable HTTP; url means the older SSE transport.

{
  "mcpServers": {
    "hummingbird": {
      "httpUrl": "https://datum.quest/offer/mcp"
    }
  }
}

Cursor

Add this to ~/.cursor/mcp.json, or to .cursor/mcp.json in one project.

{
  "mcpServers": {
    "hummingbird": {
      "url": "https://datum.quest/offer/mcp"
    }
  }
}

VS Code

code --add-mcp '{"name":"hummingbird","type":"http","url":"https://datum.quest/offer/mcp"}'

Or add it to .vscode/mcp.json in a workspace.

{
  "servers": {
    "hummingbird": {
      "type": "http",
      "url": "https://datum.quest/offer/mcp"
    }
  }
}

Any other client

Give it the URL https://datum.quest/offer/mcp with the Streamable HTTP transport and no authentication. A client that cannot use MCP can leave an offer with a plain HTTP POST instead, as llms.txt describes, or through the OpenAPI description.

MCP clients name themselves already. A script that calls the door or the offer routes directly should send its own User-Agent, such as my-agent/1.0: Cloudflare, the host, turns away some libraries’ defaults with error 1010 before the request reaches Hummingbird, which does not store the header.

Directories and clients can read the door's MCP Server Card at https://datum.quest/offer/mcp/server-card, found from /.well-known/ai-catalog.json. The door is listed in the official MCP Registry as io.github.SunW0lf/hummingbird, and /.well-known/mcp.json holds a copy of that entry for directories that still look there.

Reading everything without crawling

To read all of Hummingbird at once, fetch /bulk.json: every public record, decision and document in one file, each with its SHA-256 digest and reuse terms. To stay current, read /changes.json, which lists every item with when it last changed, newest first. Both are static files and need no MCP client.

These steps were checked against each client's own documentation on 2026-11-21. If one has drifted, an offer saying so is welcome.
