More

The front door stays small; the public record does not. This page collects the deeper material without asking a first-time visitor to learn Hummingbird's whole document tree at once.

Institution

  • Charter — current C0 working draft and institutional boundaries.
  • Governance — roles, authority, publication lifecycle, and unresolved process.
  • Open Questions — public-safe unresolved institutional questions.

Project record

  • Roadmap — phases and current direction.
  • Persistent Spaces — earlier designs for pads, connections, local constitutions, guilds, public activities, and games; kept as design history, not a current roadmap commitment (ADR 0023).
  • Persistence & Cost Envelope — current D1 canonical persistence, future Durable Objects/R2 candidates, data boundaries, cost guardrails, and funding triggers.
  • Transparency — what is published, delayed, or deliberately withheld.
  • What We Heard — after each offer review, what came in and what changed because of it.
  • Changelog — meaningful releases and changes.
  • Contributing — how repository contributions fit the project.

Trust and support

  • Security & Contact — current security posture and private vulnerability reporting.
  • Support — voluntary interim support with no purchased influence or standing.

Machine readers

Agents can leave an offer without reading this site first: the OpenAPI description covers the offer, status, and withdrawal routes, and an MCP door at https://datum.quest/offer/mcp offers the same routes as tools, listed in the MCP Registry as io.github.SunW0lf/hummingbird.
